01 — PERSONAL PROJECT

LMS — Learning Management System

A role-based learning platform for Students, Instructors, and Admins, covering course creation through paid enrollment and completion tracking.

React.jsNode.jsExpress.js MongoDBRedux ToolkitSocket.IORazorpay

Problem

Course platforms need three very different experiences — admin moderation, instructor authoring, and student consumption — to share one consistent backend without the roles stepping on each other's data or permissions.

Solution

A single MERN application with role-based access control at the route level, where JWT identity determines what a request is even allowed to touch — not just what the UI shows.

Architecture

  • Controller–service–middleware–model layering on the backend, keeping route handlers thin and business logic testable in isolation.
  • MongoDB/Mongoose aggregation pipelines for reporting-style views (progress, enrollment) instead of pulling full documents client-side.

Authentication & authorization

  • JWT issued on login, stored in HTTP-only cookies rather than local storage, to reduce exposure to XSS.
  • Protected routes gate access by role — student, instructor, admin — on both client and server.

Payment flow

Razorpay handles checkout for paid courses; the backend confirms payment server-side and writes enrollment as a MongoDB transaction, so a student is never enrolled without a matching payment record.

Real-time communication

Socket.IO delivers persistent notifications through authenticated, user-specific rooms — each user only receives events addressed to their own session, not a broadcast to every connected client.

Key features by role

Admin: user management and a pending → approved/rejected course review workflow
Instructor: course creation, course management, lecture management
Student: enrollment, course player, lecture-level progress tracking
Platform: completion tracking tied to progress across all lectures in a course

Engineering decisions

Splitting the backend into distinct layers made the course-approval workflow easy to extend without touching payment logic, and kept the Socket.IO notification layer decoupled from the core REST API — notifications are pushed as a side effect, not a blocking part of any request.

02 — PERSONAL PROJECT

AI-First CRM — AI-Powered Healthcare CRM

A CRM for Medical Representatives that replaces traditional data-entry forms with natural-language conversation for logging and managing Healthcare Professional interactions.

React.jsFastAPILangGraph LangChainGroqSQLAlchemySQLiteRedux ToolkitAxios

Problem

Medical Representatives log HCP interactions constantly, and structured forms slow that down — the same information (who, what was discussed, follow-ups) is easier to say than to fill in field by field.

Solution

An AI agent that understands the conversation, calls the right tool for the intent (log, edit, search, follow up), and writes structured records behind the scenes — so the rep talks, and the CRM stays in sync.

Architecture

FastAPI backend with a layered Service–Repository architecture, keeping data access separate from business logic so the agent's tools call services rather than touching the database directly.

AI agent & tool calling

A LangGraph-based agent routes each message to one of several tools: interaction logging, interaction editing, HCP search, interaction history, and follow-up suggestions — rather than one large prompt trying to do everything at once.

Structured data synchronization

The React and Redux Toolkit frontend keeps the conversational assistant and the structured CRM views in sync — when the agent logs or edits an interaction, the same data has to reflect correctly in both the chat transcript and the structured record view, via Axios calls back to the FastAPI service layer.

Engineering decisions

Tool calling over a single freeform prompt made behavior more predictable — each action the agent can take is a discrete, testable function rather than something inferred purely from generated text, which matters more in a CRM than in a general chat assistant.
